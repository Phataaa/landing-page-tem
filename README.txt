CARAFIX CHRISTMAS LANDING PAGE

1. Install Node.js (LTS).
2. Extract this project.
3. Open a terminal in the project folder.
4. Run: npm install
5. Run: npm run dev
6. Open the local URL shown by Vite.

IMPORTANT BEFORE PUBLISHING:
- Replace the demo Unsplash images with approved Carafix photos.
- Confirm addresses, service descriptions and any claims with Carafix.
- Connect the enquiry form to the business email/CRM/WordPress form handler.
- Add the approved phone number and privacy policy link.
